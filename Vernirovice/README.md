# Vernířovice

Samostatná kapitola dokumentace lokality Vernířovice. Hlavním tématem je místní Home Assistant a řízení energetiky kolem FVE a bateriových systémů.

## Projekty

- [Home Assistant](Home-Assistant/README.md) – současná instance, provozní služby, integrace a plánovaná migrace na Qotom.
- [BESS a FVE](BESS-a-FVE/README.md) – měniče, baterie, omezení přetoků a automatizace řízení energie.
