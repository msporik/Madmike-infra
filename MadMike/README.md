# MadMike

Kapitola dokumentace provozované infrastruktury MadMike.

## Projekty

- [Monitoring](Monitoring/README.md) – dohled nad Proxmoxem, PBS, MikroTiky a dostupností služeb; návrh společných Telegram notifikací.
- [Servery](Servery/README.md) – produkční a DR Proxmox servery, důležité virtuální stroje a infrastruktura přístupu k serverovým službám.
- [Síť](Sit/README.md) – adresní plán, MikroTik zařízení a obecná síťová infrastruktura.
- [Home Assistant](Home-Assistant/README.md) – domácí automatizace, Zigbee, FVE SolaX a interkom Hikvision.
- [Zálohy](Zalohy/README.md) – PBS, disaster recovery, testy obnovy a zálohy dalších systémů.

Další projekt se přidá až při zahájení konkrétní práce. Tento soubor slouží jako rozcestník kapitoly.
